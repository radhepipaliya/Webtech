# Web Technology Learning Repository

A comprehensive collection of web development tutorials and examples covering HTML, CSS, and JavaScript fundamentals to advanced concepts.

## 📚 Repository Structure

This repository is organized into three main sections with daily lessons and practical examples:

### HTML
Foundational HTML concepts and elements:
- **Day-04-AnchorTag**: Hyperlinks and navigation
- **Day-05**: Basic HTML structure
- **Day-05 Tables**: HTML tables and data presentation
- **Day-06 Forms**: Form elements and input types
- **Day-08 Multimedia**: Audio and video integration
- **Day-09 Marquee**: Scrolling text elements
- **Homework & Tasks**: Practice exercises

### CSS
Styling and layout techniques from basics to advanced:
- **Day-01**: CSS Selectors and Introduction
- **Day-02**: Pseudo-class Selectors
- **Day-03**: Pseudo-elements and Text Properties
- **Day-04**: Box Model
- **Day-05**: CSS Gradients
- **Day-06**: Background Properties
- **Day-07**: CSS Positioning
- **Day-08-10**: Flexbox Layout
- **Day-11-13**: Grid Model
- **Day-14-15**: CSS Transformations and Transitions
- **Day-16-17**: CSS Animations
- **Day-18**: Media Queries (Responsive Design)
- **Day-19**: List Styling
- **Tasks**: Practice projects

### JavaScript
From fundamentals to modern ES6+ features:
- **Day-01-02**: Introduction and Variables
- **Day-03**: Scopes
- **Day-04**: Data Types and Operators
- **Day-05-09**: Functions (including advanced concepts)
- **Day-10**: Strings
- **Day-11**: Arrays
- **Day-12**: Objects
- **Day-13**: Array Iteration Methods
- **Day-14-15**: Math and Date Objects
- **Day-16**: Call, Apply, and Bind
- **Day-17-18**: ES6 Concepts and Modules
- **Day-19-21**: DOM Manipulation
- **Day-22**: Event Handling
- **Day-25**: Browser Object Model (BOM)
- **Day-26**: Timing Functions
- **Day-27**: JSON
- **Day-28**: Promises
- **Day-29**: Fetch API
- **Day-30**: Web APIs
- **Day-31**: EmailJS Integration

## 🎯 Learning Path

Each directory contains:
- Practical code examples
- Hands-on exercises
- Real-world use cases
- Progressive difficulty levels

## 📖 Notes

- HTML concepts

- JavaScript fundamentals

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/radhepipaliya/Webtech.git
   ```

2. Navigate to any topic folder:
   ```bash
   cd Webtech/HTML/Day-05
   ```

3. Open the HTML files in your browser to see the examples in action

## 💡 Usage

- Browse through the organized day-by-day lessons
- Start with HTML basics and progress to CSS and JavaScript
- Each folder contains self-contained examples
- Practice with the provided tasks and homework assignments
